# Tutorial brief: Run your LangChain in Docker Sandboxes

Reader: a Python/LangChain developer with an existing app, comfortable with
Docker and a terminal. Outcome: inspect resources, choose access explicitly,
review v3 packaging, run the app inside local SBX and understand the cloud delta.

Use the same ticket-triage app in agent-assisted and manual paths. Show the
mixin/workload distinction, sanitized snapshot and permission summary. Separate
offline/build/TCK/container results from unrun actual SBX/live checks. Link the
host handoff rather than inventing a runtime transcript. Explain allowed-service
side effects and production gaps. The policy lab is supporting, not the lead.

No customer story, author identity, corporate endorsement or public launch is
asserted. Reader-facing text: [article](run-your-langchain-in-docker-sandboxes.md)
and [guide](user-guide.md). Editorial status: [process](editorial-process.md).

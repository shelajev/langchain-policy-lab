# Audience prerequisites

The reader writes Python/LangChain applications, understands virtual environments
and dependency locks, can use a shell, and knows what an API
key is. They have this repository checkout and can follow relative file paths.
They are new to Docker Sandboxes and may not know shell workloads,
credential binding, environment-file syntax or cloud limitations. They want to
run their existing app unchanged, with reusable kits optional. Docker buildx
and kit-tck are prerequisites only for optional packaging. Runtime steps need
a separately approved supported host with Docker Sandboxes and `sbx`.

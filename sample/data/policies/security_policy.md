# Information security
## Classification
Data classification levels are Public, Internal, Confidential, and Restricted.
## Secrets
Store API keys and secrets in the approved credential vault. Never commit secrets to source control.
## Passwords
Passwords must contain at least 14 characters. Use multifactor authentication.
## Devices
Company devices must use full disk encryption.
